# TubeCutter

**เลิกดาวน์โหลดวิดีโอทั้งไฟล์ แล้วเอาเฉพาะช่วงที่ต้องการ**

TubeCutter เป็นวิธีที่เร็วที่สุดในการบันทึกเฉพาะส่วนของวิดีโอ YouTube ที่คุณต้องการ วางลิงก์ ดูตัวอย่าง ลากเพื่อกำหนดจุดเริ่มและจุดจบ แล้ว TubeCutter จะตัดเฉพาะช่วงนั้นเป็นไฟล์ที่เรียบร้อย ใส่คลิปลงคิวได้ไม่จำกัด หยุดชั่วคราวหรือยกเลิกได้ทุกเมื่อ และเก็บเฉพาะคลิปที่คุณชอบ สร้างมาสำหรับ Windows และ Mac

**สถานะรุ่นปัจจุบัน:** ตัวติดตั้ง Windows x64 เผยแพร่ใน[รุ่น v0.1.1](https://github.com/MolecularDust/TubeCutter/releases/tag/v0.1.1) แล้ว ยังไม่ได้ลงนามโค้ด ดังนั้น Windows SmartScreen อาจแจ้งเตือนเมื่อเปิดครั้งแรก ไฟล์ `.app` และ `.dmg` ของ macOS สำหรับ Apple Silicon เป็นบิลด์ประเมินผลในเครื่องที่ใช้งานได้ การทดสอบเมทาดาทา/การดาวน์โหลดของเครื่องมือที่ลงนามแล้ว และการตรวจความสมบูรณ์ของลายเซ็นและอิมเมจผ่านทั้งหมด ข้อยกเว้นการตรวจสอบไลบรารีที่ผู้ใช้อนุมัติใช้กับ yt-dlp เท่านั้น แอปหลักยังคงการตรวจสอบไว้ และ Deno ทำงานโดยปิด JIT ดู[รายละเอียดการลงนาม](../SIGNING_APPROVAL.md) บิลด์นี้ลงนามแบบ ad hoc ไม่ได้ลงนามด้วย Developer ID และไม่ได้ผ่านการ notarize

## ดาวน์โหลด

- **Windows:** [ดาวน์โหลดรุ่นล่าสุด](https://github.com/MolecularDust/TubeCutter/releases/latest) เลือกการติดตั้งแบบปกติหรือสำเนาแบบพกพา
- **macOS:** [ดาวน์โหลดรุ่นล่าสุด](https://github.com/MolecularDust/TubeCutter/releases/latest)

## ตั้งค่าการเข้าถึง YouTube

1. ติดตั้ง TubeCutter แล้วเปิด **บัญชีและการตั้งค่า**
2. ในเมนู **การยืนยันตัวตน** เลือก **เซสชัน YouTube ของแอป**
3. คลิก **ลงชื่อเข้าใช้ Google** แล้วลงชื่อเข้าใช้ให้เสร็จ

พร้อมใช้งาน TubeCutter แล้ว

หากต้องการใช้เบราว์เซอร์ที่คุณลงชื่อเข้าใช้ไว้แล้วแทน ให้เลือก Chrome, Firefox หรือ Opera ใต้ **การยืนยันตัวตน** บน Windows ให้ปิดเบราว์เซอร์นั้นก่อนเริ่ม ใช้เฉพาะบัญชีของคุณเอง อย่านำเข้าหรือแชร์คุกกี้ของผู้อื่น

คุณจะคงไว้ที่ **ไม่ระบุตัวตน** ก็ได้ แต่การตรวจสอบบอตของ Google เข้มงวดกว่าสำหรับการเข้าถึงแบบไม่ระบุตัวตน

## การใช้งาน

1. เลือกโฟลเดอร์ปลายทางด้วยตัวเลือกของระบบ
2. วางลิงก์ YouTube (watch, youtu.be หรือ Shorts) แล้วคลิก วิเคราะห์
3. ใช้เครื่องเล่น YouTube แบบเต็มความกว้าง ตัวควบคุมของเครื่องเล่นเองจัดการการเล่นและระดับเสียง
4. ไทม์ไลน์จะเปิดใช้งานเองหลังการวิเคราะห์ หากไม่เปลี่ยน เริ่ม/จบ ก็จะดาวน์โหลดวิดีโอทั้งหมด การเปลี่ยนจุดใดจุดหนึ่งคือการเลือกช่วงตัด รีเซ็ต คืนเป็นวิดีโอทั้งหมด ลาก เริ่ม/จบ แก้ไข HH:MM:SS(.mmm) หรือใช้ ตั้งจุดเริ่ม/ตั้งจุดจบ I/O ใช้ได้นอกช่องกรอก และปุ่มเว้นวรรคสลับการเล่น ลากสามเหลี่ยมสีแดงเหนือแทร็กเพื่อเลื่อนหัวเล่นโดยไม่ขึ้นกับ เริ่ม/จบ ปุ่มลูกศรเลื่อนเครื่องหมายหรือหัวเล่นที่เลือกอยู่ทีละ 0.1 วินาที Shift+ลูกศรทีละ 1 วินาที Home/End พาหัวเล่นไปที่ขอบของวิดีโอ
5. ส่วนเผื่อ ค่าเริ่มต้นคือ 00 วินาที และขยายทั้งสองปลายโดยหยุดที่ขอบของวิดีโอ ความยาว แสดงความยาวที่ได้เมื่อรวมส่วนเผื่อ เริ่ม, จบ, ส่วนเผื่อ และ ความยาว มีปุ่มขึ้น/ลงทีละหนึ่งวินาที ปุ่มของ ความยาว ปรับ จบ ดูตัวอย่างส่วนที่เลือก เล่นช่วงที่รวมส่วนเผื่อ และเปลี่ยนเป็น หยุด ระหว่างเล่น เลือกการตัดแบบเร็วหรือ ตัดแบบแม่นยำ
6. การตั้งค่าดาวน์โหลด เปิดอยู่ในตอนแรก คลิกที่หัวข้อเพื่อพับหรือเปิดอีกครั้ง เลือกคอนเทนเนอร์ ความละเอียดต้นฉบับจริง โคเดก เสียง คำบรรยาย และโหมด แล้วเพิ่มลงคิว
7. หยุดชั่วคราว (หยุดชั่วคราว/ทำต่อ) หรือยกเลิก (ยกเลิก) การดาวน์โหลดที่กำลังทำงาน ลองใหม่รายการที่ล้มเหลวด้วย ลองอีกครั้ง และแสดงไฟล์ที่เสร็จแล้วด้วย แสดงใน Finder ล้างรายการที่เสร็จแล้ว ลบแถวที่เสร็จ ยกเลิก และล้มเหลว โดยคงงานที่กำลังทำงานและไฟล์ที่บันทึกไว้

**บัญชีและการตั้งค่า** เป็นแบบไม่ระบุตัวตนโดยค่าเริ่มต้น **ลงชื่อเข้าใช้ Google** / **เชื่อมต่อ YouTube** เปิดหน้าของ Google เองในหน้าต่างของแอป ซึ่งการลงชื่อเข้าใช้จะคงอยู่ในที่เก็บเว็บของแอป เมื่อเลือก _เซสชัน YouTube ของแอป_ ต่อมา yt-dlp จะได้สแนปช็อตคุกกี้ส่วนตัวต่อหนึ่งงาน (โหมด 0600 ลบหลังใช้เสร็จและล้างตอนเริ่มต้น) โดยไม่เข้าถึงเบราว์เซอร์หรือพวงกุญแจ

การเลือกเบราว์เซอร์คืออนุญาตอย่างชัดเจนให้เข้าถึงคุกกี้ของเบราว์เซอร์นั้นในภายหลัง และอาจทำให้ระบบขอสิทธิ์ อย่านำเข้าหรือแชร์คุกกี้ของผู้อื่น โฟลเดอร์การตั้งค่าของแอปเก็บเฉพาะพาธและค่ากำหนด การยืนยันตัวตนเป็นทางเลือก

## ภาษา

อินเทอร์เฟซของแอปมีภาษาอังกฤษและอีก 19 ภาษา: อาหรับ เบงกาลี จีน (ตัวย่อ) ฟิลิปปินส์ ฝรั่งเศส เยอรมัน ฮินดี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี เปอร์เซีย โปรตุเกส (บราซิล) รัสเซีย สเปน เตลูกู ไทย ตุรกี และเวียดนาม โดยค่าเริ่มต้นจะใช้ภาษาของระบบ หากต้องการเลือกภาษาอื่น ให้เปิด **บัญชีและการตั้งค่า → ภาษา** การเลือกมีผลทันทีและถูกจดจำไว้ ภาษาอาหรับและเปอร์เซียจัดวางจากขวาไปซ้าย หน้าของตัวติดตั้ง macOS ก็ใช้ภาษาของ Mac ของคุณเช่นกัน
